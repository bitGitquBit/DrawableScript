# DrawableScript
A script for English I designed to "draw" words and sentences.

## Core Principles
* **Purely Phonetic:** Words are written exactly as they sound based on the International Phonetic Alphabet (IPA).
* **Silent Letter Elimination:** No redundant or silent letters (e.g., "knight" becomes four phonetic glyphs).
* **Unique Typography:** A completely custom visual language optimized for modern writing aesthetics.

## Repository Structure
* `README.md` — Project introduction, design goals, and sample texts.
* `alphabet.md` — The complete phonetic-to-glyph directory with visual assets.
* `/glyphs` — A folder containing individual `.svg` or `.png` images for every character.
